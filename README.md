## Description du projet

Ce projet est un portfolio personnel conçu pour présenter les compétences et les réalisations de l'auteur. Il utilise des technologies modernes pour offrir une expérience utilisateur fluide et esthétique. Le portfolio inclut des sections pour les projets, un CV, et des images pertinentes, le tout organisé de manière intuitive.

### Fonctionnalités clés
- Présentation des projets réalisés
- Section dédiée au CV
- Design réactif grâce à Bootstrap et Tailwind CSS
- Utilisation de JavaScript pour des interactions dynamiques

## Instructions d'installation

### Prérequis
- Un navigateur web moderne
- Un éditeur de code (facultatif, mais recommandé)

### Étapes d'installation
1. Clonez le dépôt :
   ```bash
   git clone https://github.com/Randimbisoa179/portfolio.git
   ```
2. Accédez au répertoire du projet :
   ```bash
   cd portfolio
   ```
3. Ouvrez le fichier `accueil.html` dans votre navigateur pour visualiser le portfolio.

## Utilisation

Pour exécuter le projet, ouvrez simplement le fichier `accueil.html` dans un navigateur web. Vous pourrez naviguer à travers les différentes sections du portfolio.

### Exemples d'utilisation
- Cliquez sur les liens des projets pour voir les détails.
- Téléchargez le CV au format PDF disponible dans la section appropriée.

## Structure du projet

Voici un aperçu de la structure du projet :

```
portfolio/
├── bootstrap-5.3.3-dist/  # Contient les fichiers Bootstrap CSS et JS
│   ├── css/                # Fichiers CSS de Bootstrap
│   └── js/                 # Fichiers JavaScript de Bootstrap
├── css/                    # Fichiers CSS personnalisés
│   └── style.css           # Fichier CSS principal du projet
├── image/                  # Images utilisées dans le portfolio
│   ├── Capturea.PNG        # Capture d'écran
│   ├── cv1.pdf             # CV en PDF
│   ├── Gemini.png          # Autre image
│   └── image.jpg           # Image supplémentaire
├── tailwindcss/            # Fichiers de configuration et de styles Tailwind CSS
│   ├── dist/               # Fichiers compilés de Tailwind CSS
│   ├── index.css           # Fichier principal de styles Tailwind
│   ├── package.json        # Fichier de configuration pour Tailwind
│   └── README.md           # Documentation de Tailwind CSS
├── accueil.html            # Page d'accueil du portfolio
└── netlify.toml           # Configuration pour le déploiement sur Netlify
```

### Explication des répertoires principaux
- **bootstrap-5.3.3-dist/** : Contient les fichiers nécessaires pour utiliser Bootstrap, y compris les CSS et JS.
- **css/** : Contient les fichiers CSS personnalisés pour le style du portfolio.
- **image/** : Répertoire pour toutes les images utilisées dans le projet.
- **tailwindcss/** : Contient les fichiers nécessaires pour utiliser Tailwind CSS, y compris les configurations et les styles.
- **accueil.html** : Le point d'entrée principal pour le portfolio.
- **netlify.toml** : Fichier de configuration pour le déploiement sur Netlify.
